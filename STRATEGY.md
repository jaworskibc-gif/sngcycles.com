# SNG (Shark Not Goldfish) — Brand Strategy, Research & Build Guide

**Tagline:** Our shit leaves the school behind.  
**Product:** Full-size electric hyper-moto · Founders Series · 30 units · $20,000 MSRP  
**Positioning:** Luxury ICE-buyer (Ducati / Husqvarna / BMW) — never "e-bike."

---

## Phase 1 — Competitor & Trend Research

### What premium motorcycle brands do well

| Brand | Pattern to steal | Pattern to avoid |
|-------|------------------|------------------|
| **Arch Motorcycle** | Bespoke language, "handcrafted for you," dark minimal layout, co-design narrative | Over-soft lifestyle without proof |
| **Stark Future** | Specs as facts (HP, torque, battery Wh), limited editions (500 units), product-card clarity, "feel it to believe it" | Tech-gadget / mass-market catalog feel |
| **Ducati** | Emotional headline + technical depth, bold condensed typography, red/black drama | Race-team cliché overload |
| **Porsche / hypercar allocation** | Invite-only allocation language, application → deposit → confirmation, scarcity as status | Standard e-commerce cart |

### Luxury launch-page conventions (2025–2026)

1. **Full-bleed immersion first** — video or raw photography, not product renders  
2. **Editorial typography** — large display type, tight tracking, restrained body copy  
3. **Proof over promise** — telemetry, macro tool marks, serialized plates, unedited garage footage  
4. **Scarcity as allocation** — "Founders Series 01/30," not "Buy now — only 30 left!"  
5. **One primary CTA** — reserve / apply, not a grid of shop buttons  
6. **Dark surfaces + metal accents** — black, graphite, brushed aluminum, single hot accent  
7. **Micro-interactions** — counters, sticky specs, subtle hover — never neon gimmicks  

### Credible "engineering blueprint" UI (not a spreadsheet)

Premium sites treat specs as **instrument panels**:

- Monospace or technical numerals for values  
- Thin rule lines, grid coordinates, unit labels in small caps  
- Grouped by system (Chassis / Powertrain / Geometry)  
- Side annotations: *why* a number exists, not just *what*  
- Macro photography paired with each callout  
- Validation language: "Measured · Prototype #4 · Florida"  

Avoid: Excel tables, neon dashboards, "gamer RGB" UI.

### Competitive frame (internal only — never name on-site)

| Competitor class | How SNG wins without naming them |
|------------------|----------------------------------|
| Compact electric platforms | Full-size geometry, 40" seat, 58" wheelbase, tall-rider first |
| High-HP limited electrics | Lighter chassis, no artificial governor, street-real packaging |
| Premium ICE (Ducati/Husk/BMW buyer) | Quiet violence of 70HP / &lt;200lbs, billet art-object chassis, allocation model |

**Price frame:** $20k is a *feature*. "We spend more on raw components than three standard electric platforms combined."

## Phase 3 — Copywriting

### Three homepage / social hooks

**Hook A — Skepticism Killer (recommended homepage hero)**  
> **The internet says this is fake.**  
> It's parked in a garage in Florida.  
>  
> Sub: Prototype #4. Fully functional. Under 200 lbs. 70 HP. 100+ MPH. Built for riders the industry sized out.

**Hook B — Tall Rider Manifesto**  
> **Ergonomic justice for tall riders.**  
>  
> Sub: Full-size stance. 40" seat. 58" wheelbase. The lightest, fastest, tallest electric hyper-moto on the market — because no one else built it.

**Hook C — Luxury Restraint**  
> **Leave the school behind.**  
>  
> Sub: Thirty hand-built machines. CNC billet. Coil-spring Cone Valve forks. Tool-less battery swap in ten seconds. $20,000. Not for everyone.

### Tone-of-voice guide

| Do | Don't |
|----|-------|
| Hypercar / atelier language: *allocation, hand-built, serialized, billet, chassis plate* | E-bike / gadget language (ever) |
| Own skepticism: "the internet says this is fake" | Over-claim with emoji hype |
| Aggressive but precise: "our shit leaves the school behind" | Gear-brand clichés (ripped, shred, gnarly, send it) |
| Evidence-first: tool marks, telemetry, hours, dollars | Lifestyle fluff without metal |
| Quiet confidence + one punch line | All-caps rage OR pure museum whisper |
| Call the buyer by their current machine culture: Ducati, BMW, Husqvarna, track days | Bargain / "value" framing |

**Voice formula:** 70% automotive restraint · 30% counter-culture bite.

**Banned customer-facing words:** e-bike, Surron, Light Bee, "gadget," "budget," "cheap power."

**Preferred product language:** custom billet platform · hyper-moto · full-size electric motorcycle · Founders Series machine.

### Sample microcopy

- CTA primary: `Request Allocation` / `Apply for Founders Series`  
- CTA secondary: `See the Engineering`  
- Deposit: `$1,000 fully refundable reservation · secured via escrow`  
- Confirmation: `Welcome to the School`  
- Scarcity: `30 units. Serialized 01/30–30/30.`

## Phase 4 — Site Architecture

### Two-lane conversion (customer-facing only)

Public site = sales only. No ops boards, agents, trackers, or internal playbooks.

```
LANE 01 — High ticket          LANE 02 — Volume cashflow
Founders Series allocation  →  5-SKU apparel drop
$20,000 · $1k deposit          500 units/month target
founders.html                  #apparel product grid + bundles
```

### Navigation map

```
SNG
├── Two Ways In       (#lanes) — dual lane chooser
├── The Machine       (#machine + engineering proof)
├── Shop the Drop     (#apparel) — 5 SKUs hard sell
├── The Founder       (#founder)
└── Request Allocation (founders.html)
```

### Page / section responsibilities

| Surface | Job |
|---------|-----|
| **Homepage** | Kill skepticism → prove real → tell founder cost → show Kinetic Canopy → apparel as culture → allocate |
| **The Bike** | Spec instrument panel + geometry story + tall-rider comparison |
| **Engineering** | Billet vs flex, fork rationale, wheelbase, canopy mechanism, component roster |
| **Apparel** | Lifestyle identity, Founders Edition hoodie tied to deposit |
| **Founder** | 6'7" origin, 14 months, $50k, job loss, Prototype #4, dune failure → real chassis |
| **Founders Series** | Application form → escrow deposit path → Welcome email + garment |

### Build priority (fastest path to live reservations)

1. **Homepage hero + specs + Founders CTA** — one scroll path to apply  
2. **Founders application form** (name, contact, riding background, preferred serial)  
3. **Escrow / Stripe Payment Link for $1,000 deposit** (refundable, labeled clearly)  
4. **Confirmation page + "Welcome to the School" email** (Resend / Mailchimp / Zapier)  
5. **Founders Edition hoodie fulfillment trigger** (manual → Printful/Payhip automation)  
6. Engineering deep page + Kinetic Canopy video loop  
7. Apparel full grid  
8. Analytics + heatmaps (PostHog / Plausible)

### Escrow deposit notes (implementation)

- Prefer **Stripe Payment Link** or **Escrow.com** for true third-party hold until track validation  
- Application submits first → backend creates application ID → payment link emailed / shown  
- Deposit ≠ sale; balance due at track validation  
- Legal: refundable reservation terms on form + confirmation
