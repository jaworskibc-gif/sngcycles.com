2.2 — Drivetrain & Jackshaft Blueprint

The jackshaft combines power from both motors before sending it to the rear wheel, preventing the motors from mechanically fighting each other. Weld or bolt a 3/8" thick steel plate to the rear-engine cradle area. Slot bearing mounting holes by 1/2" vertically to manually adjust primary chain tension.

2.3 — Drivetrain Gear Reduction Math

Chassis Reference Baseline: Standard 25-inch tall rear tire (e.g. 180/65B16).

Stage 1 — Motors to Jackshaft: 11T motor ÷ 22T jackshaft = 2.00:1
Stage 2 — Jackshaft to Wheel: 13T jackshaft ÷ 28T rear = 2.15:1
Total System Gear Ratio: 2.00 × 2.15 = 4.30:1 Overall Reduction
Speed Ceiling @ 5,500 RPM: Rear wheel @ 1,279 RPM = 95–102 MPH top speed threshold

Section 5
Software Programming & Commissioning

BEFORE STARTING — Lift the rear wheel securely off the ground on a center stand before launching any software setup. Never perform motor detection with the wheel on the ground.

Phase 1 — Controller 1 (Master) Initialization
EBMX Tuning App via Bluetooth
  1. Turn on the 12V auxiliary system, then close the high-voltage main circuit breakers
  2. Open the EBMX Tuning App on your smartphone via Bluetooth, connect to Controller 1, rename it "Master"
  3. Navigate to Setup / Motor Tuning → Select Internal Permanent Magnet (IPM) / Axial Flux
  4. Execute Auto-Detect Motor — controller sends high-frequency pulses to calibrate against Motor 1. Save when successful
  5. Navigate to Input / Throttle Configuration — perform threshold calibration (Set Min at rest, Set Max at full twist). Save
Phase 2 — Controller 2 (Slave) CAN Integration
EBMX Tuning App via Bluetooth
  1. Disconnect from Master, connect to Controller 2 via Bluetooth, rename it "Slave"
  2. Run identical Auto-Detect Motor routine for Motor 2. Save when successful
  3. Navigate to App Settings / CAN Configuration — change Controller ID integer from 1 to 2
  4. Change Control Mode / Input Source from Local Throttle to CAN-Bus / Slave (Torque). Save
Phase 3 — Activating the Network Data Sync
Reconnect to Master Controller
  1. Disconnect from Slave, reconnect to Controller 1 (Master) via Bluetooth
  2. Navigate to App Settings / CAN Configuration and set: Controller ID = 1 · Enable CAN Status Output = ON · Multiple Controllers Over CAN = ON
  3. Open the real-time diagnostic dashboard — verify stable connection to Node 2 (Slave)
  4. Configure Regen Tuning on Master: Regen Battery Amps = -60A · Regen Phase Amps = -120A
  5. Apply 5% throttle gently — verify both primary chains drive forward uniformly. If a motor turns backward, toggle Invert Motor Direction in that controller's menu

Section 6
Mandatory Safety Testing Protocols

Perform all three verification checks on the center stand before your first test ride. Do not skip these steps.

Test 1 — Thermal Verification
  • Turn on the 12V system
  • Check the clear reservoir tank — confirm fluid is visibly moving, confirming no trapped air locks in the cooling lines
Test 2 — Safety Interlock Test
  • With the system powered ON, pull the handlebar Emergency Magnet Run-Tether
  • Twist the throttle — the display must show an error code and the motors must remain completely dead
  • If motors respond to throttle after tether pull, do not ride. Trace the interlock wiring to the EBMX Key Switch pin
Test 3 — MSD Isolation Test
  • With the system active, pull the orange Manual Service Disconnect (MSD) plug
  • The entire high-voltage dashboard communication loop must drop instantly
  • This proves the high-voltage path is safely open and dead — if any HV indicator remains live, trace the circuit before riding
